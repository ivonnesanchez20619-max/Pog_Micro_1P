# Prácticas de Webots 

## Tutorial 1: Tu primera simulación en Webots

En este tutorial se creó la primera simulación en Webots, conociendo el entorno de trabajo y agregando un robot E-puck al escenario.

**Archivo:** `my_first_simulation.wbt`

## Tutorial 2: Modificación del entorno

En este tutorial se modificó el entorno de simulación. Se ajustó el tamaño del piso, se agregaron esferas y se colocaron paredes alrededor del escenario. También se utilizaron nodos y los conceptos DEF y USE para reutilizar elementos.

**Archivo:** `obstacles.wbt`

## Tutorial 3: Apariencia

En este tutorial se modificó la apariencia visual del entorno. Se trabajó con colores, materiales y texturas para mejorar la presentación de los objetos de la simulación.

**Archivo:** `appearance.wbt`

## Tutorial 4: Más sobre controladores

En este tutorial se creó un controlador para el robot E-puck. Se utilizaron los sensores de distancia para detectar obstáculos y se programaron los motores de las ruedas para que el robot pudiera desplazarse y evitar colisiones.

**Archivo:** `collision_avoidance.wbt`

## Tutorial 5: Sólido compuesto y atributos de física

En este tutorial se creó un sólido compuesto en forma de mancuerna utilizando un cilindro y dos esferas. También se configuraron propiedades físicas como la masa, el centro de masa, la rotación y la fricción.

**Archivo:** `compound_solid.wbt`
